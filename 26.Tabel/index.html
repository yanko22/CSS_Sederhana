Belajar Tabel

  • Saat kita membuat element Tabel di HTML, kita akan banyak menggunakan Box Model

Table Border

  • jika kita ingin mengatur border pada tabel, kita bisa menggunakan Border pada table tr,th,td dan lain-lain
  • Border Property - MDN
  • saat menggunakan borde, kadang tiap kolim akan ada jarak, kita ingin menghilangkan jaraknya, kita bisa mnegunakan border-collapse
  • Border Collapse Property - MDN
  • atau kita bisa juga tambahkan padding pada bagian-bagian tabel
