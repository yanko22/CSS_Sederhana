CSS List

  • Property list-style-type bisa kita gunakan untuk mengubah jenis list yang ditampilkan di tiap item
  • list-style-type
  • Property list-style-image bisa digunakan untuk mengubah item list dalam bentuk gambar
  • list-style-image
  • Property list-style-position bisa kita gunakan untuk mengubah posisi item dan list
  • list-style-position
  • atau kita bisa menggunakan shortcut list-style untuk mengubah semua property list diatas
  • list-style
