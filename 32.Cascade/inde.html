Cascade

  • saat kita menggunakan CSS, kita harus memahami konsep cascade
  • Cascade adalah logika bagaimana web browser mengumpulkan property CSS dari berbagai sumber sebelum diterapkan ke element yang dipilih
  • Web Broeser akan mengambil sumber property CSS dari 3 sumber, Yaitu User Agent, Author dan User
