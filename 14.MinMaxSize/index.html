Min dan Max Size

  • Saat menambahakan size pada element, kadang kita menentukan size, kita perlu menentukan minimal dan maksimal dari size element, hal ini untuk menjaga element tidak terlalu kecil atau terlalu besar.
  • Kita dapat mengatur ke-dua nya pada tampilkan web menggunakan CSS.
  • Properti min-width dan max-width digunakan untuk menentukan ukuran minimum dan maksimum dari sebuah element secara horizontal.

Min Size

  • Untuk mengatur minimal kita bisa menggunakan properti min-width dan min-height.
  • min-height untuk mengatur tinggi minimum dari sebuah element.

Min Size

  • Untuk mengatur manimal kita bisa menggunakan properti min-width dan min-height.
  • min-height untuk mengatur tinggi minimum dari sebuah element.
  • Contoh Min Size
  • min-width untuk mengatur lebar minimum dari sebuah element.
  • Contoh Min Height

Max Size

  • Untuk mengatur maksimal kita bisa menggunakan properti max-width dan max-height.
  • max-height untuk mengatur tinggi maksimum dari sebuah element.
  • Contoh Max Size
  • max-width untuk mengatur lebar maksimum dari sebuah element.
  • Contoh Max Height
